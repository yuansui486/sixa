# Bundled Chinese replacement font

Noto Sans SC variable TrueType font, distributed under the SIL Open Font License
1.1 in `OFL.txt`. Copyright remains with the Noto project contributors.

Pinned source: google/fonts commit `e44c4b011a820c2cbe2fd2cfa8052037d7edb571`,
`ofl/notosanssc/NotoSansSC[wght].ttf`. The unmodified bytes are compiled into the
application so replacement text never depends on installed system fonts.
