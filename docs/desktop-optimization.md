# 桌面体验与资源优化验收

本轮针对私匣 1.0.8 工作区，目标是普通办公电脑上的文档复核体验。保留现有任务和设置；数据库从版本 2 自动升级到版本 3。仅面向 Windows/macOS 桌面，最小窗口为 960 × 640。

## 交互调整

- 工作台以文档为主体，复核面板并排显示、可调宽度；侧边栏支持自动折叠和固定状态。
- PDF/图片直接显示页面预览，按需加载可见页；浏览、框选、调整区域分开操作。实体显示实际替换内容，并与页面上的区域联动。
- 实体和手工区域共用保存队列；离开页面、退出登录、关闭窗口前等待保存，失败时保留修改并提供重试。服务器校验版本，重试使用同一操作标识，避免丢失响应造成重复修改。
- “检查完成”单独记录；编辑后取消该确认。批次逐份检查，可导出已完成文件，重试创建新批次并保留旧记录及成功结果。
- 历史支持文件名、状态、日期及分页查询；导出默认使用原文件名加“脱敏”后缀，并可打开所在文件夹。
- 设置页集中提供处理方式、并发和工作区布局；规则支持编辑和样例测试。

## 资源控制

- 启动仅预热一个中文识别实例；OCR 与额外工作实例按需加载。连续空闲 15 分钟释放推理模型，之后处理文件时重新加载。
- 模型状态区分已安装、加载中、可用和失败。启动使用文件存在检查；下载完整性校验继续保留。
- 新安装默认并发为 1，旧设置保留。重型图像处理共用单个调度名额，避免多份 PDF 同时占用大量像素内存。
- PDF OCR 和安全重建逐页处理；保真模式只渲染发生修改的页面。重建页面在加入文档前压缩，避免保留所有页面的原始像素。
- 预览使用页清单与单页二进制接口，前端最多两个同时请求；缓存估算图片解码内存，以 96 MiB 为回收预算，可见页使用期间保留。实体列表只挂载可见范围附近的行。
- 历史筛选在 SQLite 中完成；创建额外工作连接不会把正在运行的任务误判为上次中断。
- 内置 OFL 中文字体，脱敏文字绘制不再依赖 Windows 系统字体。

## 本机资源测量

Windows 本机物理内存约 31.7 GiB。以下是 `formats` 独立进程对自动生成的空白 A4 PDF 的 Release 测量，**不是整个应用、真实简历或 8 GB 机器的峰值**；不加载模型。

| 页数 | 原全部渲染预览峰值 | 新首屏预览峰值 | 原预览耗时 | 新首屏耗时 |
| --- | ---: | ---: | ---: | ---: |
| 20 | 163.5 MiB | 14.3 MiB | 98 ms | 4 ms |
| 100 | 775.5 MiB | 14.2 MiB | 539 ms | 4 ms |
| 200 | 1540.6 MiB | 14.5 MiB | 986 ms | 4 ms |

新安全重建路径在相同空白样本上，20/100/200 页的进程峰值分别为 19.0/21.7/25.5 MiB，耗时分别为 180/864/1740 ms。空白页面易压缩，不能据此推算扫描件或高分辨率图片的处理成本。

复现（不联网）：

```powershell
cargo run --release --locked -p formats --example pdf_resources -- 100 preview
cargo run --release --locked -p formats --example pdf_resources -- 100 legacy
cargo run --release --locked -p formats --example pdf_resources -- 100 rebuild
```

探针在 Windows 输出进程峰值工作集；其他平台该字段为 0，须由系统工具另行测量。

## 验证范围

- `cargo test --workspace --locked`：98 项通过，覆盖数据库升级、复核版本冲突、区域幂等重试、批量取消及续处理、调度限流、PDF 内容删除及字体。
- `cargo clippy --workspace --all-targets --locked -- -D warnings`：通过。
- 本机现有 RaNER 模型：文本识别、预览、导出及加密恢复 smoke 通过。
- 本机现有 RaNER 与轻量 PP-OCRv4：生成的 DOCX/XLSX/XLSM 识别、文字和内嵌图片脱敏、输出重读通过；XLSM VBA 哈希不变。
- 本机现有高精度 PP-OCRv4：中文图片实际推理通过。
- 前端构建通过；Vitest 18 项、Playwright 42 项通过，覆盖 1366 × 900 与 960 × 640。已查看两种尺寸工作台截图，复核面板不覆盖文档。Playwright 使用模拟 IPC，不能代替桌面原生验收。
- 新增 `quality.yml`，配置 Windows/macOS Rust 测试和 Chromium 桌面界面测试。测试时排除打包资源，**不下载生产模型，不访问 OSS**；本轮未推送或触发远程工作流。

仍需在 macOS 原生安装包、实际 8 GB 电脑和六份私有简历上复验；本轮未重新进行 Word/LibreOffice 人工开档验收。原生 ONNX Session 构造仍无法由线程超时强行终止。本轮已避免控制界面被推理工作锁住，并支持运行中推理取消。
