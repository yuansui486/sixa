# 私匣 1.0.13

- 对比预览默认双向同步滚动，覆盖 Word 排版和大文档内容视图；支持关闭同步。
- 相同文字与类型合并展示引用数量，可整组选中、替换，也可展开逐处修改。
- 工作台增加手动查找替换，Word 支持选词填入；支持撤销以及保存为独立规则。图片/PDF 的文字替换映射到 OCR 区域。
- 生成结果先预览，保存时选择根目录或子目录，可新建文件夹，成功返回文件管理。工作台增加返回入口，历史和批量共用保存窗口。
- 文件管理展示当前目录的真实文件和子文件夹，外部文件可打开或新建任务。已有任务和历史导出记录保留。
- MCP 增加脱敏结果历史查询、目录浏览和新建目录。未指定输出目录改用保存根目录；有子文件夹时先要求用户选择。

默认行为变更：桌面生成任务不再自动导出到文件夹，结果仍保存在任务内部，稍后可从历史保存。MCP 仍会自动导出到已确认的位置。没有 Apple 签名证书，macOS 沿用现有签名与推理引擎权限配置。

本地验证：Rust 122 项测试、前端 61 项单元测试、两个桌面尺寸共 86 项流程测试，以及 WebKit 4 项新流程测试通过；Clippy、前端构建、MCP 九工具元数据自检、更新签名与版本清单测试通过。测试包含真实生成的 Office/图片文件、实际导出内容、OCR 区域像素变化、重启后撤销及重复请求恢复。浏览器流程使用模拟 IPC；实际 macOS 安装与用户文档效果仍需安装包验收。CI 使用离线样本及原生推理引擎探针，不下载生产模型包。
