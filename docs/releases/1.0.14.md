# 私匣 1.0.14

- 工作台明确区分生成预览和保存到文件夹；离开尚未保存的结果时可保存、暂不保存或留在任务。
- 保存窗口记住上次成功使用的目录，可一键保存到该位置；历史记录分别提供打开任务和打开已保存文件。
- 快速查找替换显示当前文件命中数和将被覆盖的脱敏范围；PDF/图片预览标出新命中及冲突区域。
- 部分完成任务也显示文件保存状态和保存入口；常见处理错误在当前页面提供原因及恢复操作。

本地验证：Rust 单元测试、前端 62 项单元测试、Edge 桌面端 88 项端到端流程测试及生产构建通过。发布安装包由 GitHub Actions 分别构建 Windows x64、macOS Intel 和 macOS Apple Silicon 版本。
