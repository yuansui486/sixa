# 私匣 1.0.11

- Mac 改用当前用户私有目录中的本机密钥，解决升级后重复请求钥匙串授权的问题。新安装不再需要钥匙串授权；已有数据首次升级时仍需允许读取旧密钥一次。
- 迁移保留原密钥与历史数据。拒绝授权、密钥损坏、丢失或权限异常时显示明确提示，不自动重置密钥。
- 旧版登录凭据不再额外弹出系统授权窗口；必要时重新登录。当前版本的加密登录状态保持不变。
- MCP 在应用启动未完成时停止自动重复启动，并提供用户处理指引；成功手动启动后恢复。
- Windows 的系统凭据存储方式保持不变。

Mac 本机密钥受文件权限保护，但同一账号下的其他程序可能读取它，防护弱于按应用授权的钥匙串。请妥善备份应用数据和密钥目录，不要删除旧钥匙串条目或清空历史数据来处理弹窗。

本次 CI 在 Mac Intel 与 M 系列环境验证迁移、私有文件权限、异常保护、MCP 启动门禁，以及最终安装包在钥匙串锁定后的重启；模型测试继续使用离线微型图，不下载 OSS 生产模型。
