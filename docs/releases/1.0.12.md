# 私匣 1.0.12

- 修复 Mac 一直停留在“加载 ONNX 推理引擎”：临时签名应用启用了 hardened runtime，但没有允许加载无共同 Team ID 的随包动态库。现在保留 hardened runtime，并配置必要的动态库加载权限。
- 修复推理库加载失败后的无限等待。应用直接校验并初始化 ONNX C API，避免上游封装库在错误路径重入初始化锁；缺失、损坏、不兼容或被系统拒绝的库会明确报错，可以修复后重试。
- CI 新增最终签名桌面程序的 `--check-inference-runtime` 验证，以及相同签名限制下的 NER/OCR 推理验证；缺少权限必须快速失败，补齐权限后必须成功。不下载生产模型。

已在出现故障的 Apple Silicon Mac 上复现系统的 Team ID 拒绝错误，补齐权限后现有真实实体模型用时 396 毫秒完成加载和首次推理。人工文本通过完整脱敏流程，姓名、地点、电话、邮箱均完成替换。

直接覆盖安装，无需删除钥匙串、本机密钥、任务数据或重新下载模型。Mac 请使用“应用程序”目录中的私匣；本次完整安装包和应用内更新包均包含修复。
