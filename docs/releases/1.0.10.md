# 私匣 1.0.10

- 新增“文件管理”：设置处理结果保存目录，搜索和筛选文件，预览、打开文件、定位文件夹及另存为。
- 确认生成后自动保存，默认目录为系统文稿目录下的“私匣/处理结果”；同名文件自动编号。保存失败可更换目录后重试，无需重新识别。
- 批量任务保存成功文件的 ZIP，明确提示未完成项目数量。MCP 生成的文件也会显示在文件管理中。
- 删除任务后保留已保存文件；文件移走或删除后显示状态。旧任务不会自动批量导出，可从任务历史手动保存。
- Mac 接入页增加版本、平台和可复制诊断；程序缺失时提供修复指引，不再提供无效配置。
- 模型加载超时后明确报错并取消正在进行的推理，不再无限显示加载中，也不会误报模型就绪。

## 验收说明

CI 在 macOS Intel 与 Apple Silicon 上检查最终安装包中的 MCP 程序、执行权限、签名、自动启动、桌面通信和未登录提示；验证更新包与 DMG 内容一致。

模型测试使用随包 ONNX Runtime 和离线微型图，通过生产 RaNER、OCR 加载器执行首次推理、重复推理、取消及损坏文件测试。不会下载 OSS 生产模型。此项验证加载链路，不代表已验证真实模型识别效果。

请在 Mac 安装后，用现有真实模型分别测试中文文本及扫描 PDF/图片；确认首次加载完成、第二次处理可用，并在“AI 工具接入”复制新配置后进行连接自检。

## 文件保存规则

修改保存目录只影响后续输出，不移动旧文件。MCP 显式指定的目录优先；未指定时仍保存到源文件目录。手动保存或另存为不会覆盖已有文件，请选择新的文件名。

首次升级会新增输出文件索引，保留原有任务、模型、配置与登录信息。旧版本没有记录导出路径，所以此前导出的文件不会被自动扫描导入。
