# 文件管理

在左侧打开“文件管理”，通过“更改位置”设置默认保存目录。默认使用系统文稿目录下的 `私匣/处理结果`，首次生成时创建。目录设置持久化于本机数据库，支持 Windows 与 macOS 中文、空格路径。选择目录时验证其存在及可写。

确认生成后的单文件自动保存；批量任务只自动保存一份 ZIP，包含成功文件和报告，不额外导出每个子任务。切换页面不会终止保存。输出使用临时文件及不覆盖发布，同名自动编号。

“处理完成”和“保存成功”是两个状态。保存失败保留任务结果及错误记录；选择可用目录后点击“重试保存”，不重新分析。任务已经重新编辑时，不能用旧失败记录导出新的结果，应从任务页面保存。删除任务不会删除输出记录及用户文件。

文件管理按 30 项分页，支持名称与格式筛选。只检查当前页文件是否存在，不扫描整块磁盘。预览复用对应任务版本；任务已删除或版本变更时，使用“打开文件”查看实际结果。“另存为”复制实际磁盘文件，不重新生成。外部移动或删除文件后，刷新列表显示最新状态。

## 开发入口

- `ui/src/Files.tsx`：目录设置、文件列表、工作台自动保存提示；路由 `/files`。
- `src-tauri/src/files.rs`：鉴权后的文件管理 IPC。生成完成时在后端触发自动保存；`files-updated` 事件刷新前端。
- `crates/task-engine/src/files.rs`：输出版本标识、幂等自动保存、失败重试和导出登记。SQLite 第 4 版迁移新增 `outputs` 表，不为旧任务捏造导出记录。

IPC：`get_file_directory`、`set_file_directory`、`query_output_files`、`retry_output_file`、`open_output_file`、`output_task_view`、`copy_output_file`。查询支持 `search`、`kind`、`task_id`、`offset`，返回 `items` 与 `total`。记录保存任务 ID、版本、实际路径、大小、来源和保存错误，不保存文档正文。

MCP 保持既有输出目录优先级，在最终文件发布后登记输出；临时文件不进入列表。恢复包含有原始敏感内容，因此继续由用户显式导出，不自动生成。
