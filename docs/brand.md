# 私匣品牌说明

## 名称

- 中文品牌：私匣
- 英文品牌：Sixa
- 产品全称：私匣 · 本机数据脱敏
- 开发标识：`sixa`

“私”表示隐私数据只在用户授权的本机范围内处理，“匣”表示文件被收纳在明确的安全边界中。英文 `Sixa` 与中文读音对应，适合用作程序名、包名和配置标识。

## 开发命名

| 用途 | 名称 |
| --- | --- |
| 桌面程序 | `sixa.exe` |
| MCP 程序 | `sixa-mcp.exe` |
| Rust 桌面包 | `sixa` |
| Rust MCP 包 | `sixa-mcp` |
| 前端包 | `sixa-ui` |
| MCP 服务名 | `sixa` |
| 应用标识 | `cn.shierkeji.sixa` |
| 建议仓库名 | `sixa-desktop` |

历史数据继续存放在 `%LOCALAPPDATA%\LocalDesensitization\`，Windows Credential Manager 兼容标识也保持不变，避免升级后重复下载模型或丢失任务与登录状态。

## Logo

图形由半封闭匣盒、文件和一段暖色替换块组成，表达敏感片段在本机完成识别和替换后进入受控边界。图形不使用常见的盾牌、锁头、指纹或渐变科技效果。

矢量母版位于 `ui/src/assets/sixa-mark.svg`。界面使用图形与实时文字组合，不把中英文名称烘焙进图片。

| 用途 | 色值 |
| --- | --- |
| 主色 | `#126C60` |
| 纸张和匣体 | `#F8FBFA` |
| 匣口和折角 | `#B9DDD7` |
| 隐私替换强调 | `#E5AD45` |

Logo 周围至少保留图形宽度八分之一的空白。小于 24 px 时只使用图形，不附加文字；不得拉伸、旋转、添加渐变、阴影或外发光。
