# 文档预览与复核验收（1.0.8 工作区）

## 使用方式

打开文件后默认显示原件和识别标注。点击实体可定位到对应文字或图像区域，筛选条件不会阻止定位。可切换脱敏效果、对照、适合宽度或整页，缩放范围为 50%–300%。专注模式临时收起侧栏和复核面板；退出后恢复布局。

Word 使用内置轻量排版，无须安装 Office。正文、表格与嵌入图片在同一文档中展示。轻量排版的分页、字体和浮动对象位置可能与 Word 不同；未可靠定位的内容提供单独复核入口。点击图片进入原始图片坐标的复核视图，同一资源的多次引用共用修改。XLSX/XLSM 分别提供文字与内嵌图片入口，图片不作为工作表页码展示。

## 效果与实际输出

- PDF 和图片的草稿效果使用 Rust 导出处理路径；安全重建、保真 PDF 各自复用对应导出逻辑。
- 修改保存完成、停顿 500 ms 后才请求当前页效果。原件模式不计算草稿效果。翻页、离开任务或再次修改会丢弃过期显示，并取消无使用者的草稿请求。
- 已生成文件读取失败时显示错误和重试，不回退为原件或模拟效果。
- Word 在源文档的 XML 位置插入仅供显示的书签，实体通过 UTF-16 区间映射到这些位置，不按全局同名文字猜测位置。编辑文字不重新解析整个 DOCX；最终结果重新读取已生成文件。
- 显示书签及预览清理只作用于展示副本，不进入用户导出文件。

## 资源与隔离

图片请求上限为 2，缓存以编码大小加估算解码内存计算 96 MiB 回收预算；使用中的图片暂时保留，释放后参与回收。原件像素跨复核版本复用。当前页放大时最高请求 2400 px，其余使用 1400 px。原件及草稿页面的重型处理与导出共用单个图像调度名额。

DOCX 排版模块单独按需加载。解压后超过 50 MiB、展示节点超过 10000 或不支持的排版，提供分块内容视图。展示包去除外部关系、嵌入网页和活动内容；浏览器在独立 Shadow DOM 中展示，并再次限制资源和样式。关闭预览释放其对象 URL、观察器及 DOM。

- `cargo test --workspace --locked`：117 项通过。包含两种 PDF 模式、旋转中间页和 PNG/JPEG/BMP/TIFF 草稿与导出像素一致性；未修改页保持一致。
- `cargo clippy --workspace --all-targets --locked -- -D warnings`、Rust 格式检查通过。
- Vitest：52 项通过，覆盖过期响应、共享请求取消、草稿与输出分离、原件缓存复用、Word 跨 run 映射、撤销、图片串行更新、分块视图及真实 0.4.1 渲染器。
- Playwright：68 项通过，覆盖 1366 × 900 和 960 × 640；包含真实 DOCX 并排单元格、彩色图片解码、效果更新与原图恢复，已检查两种尺寸截图。浏览器测试的 IPC 为模拟接口。
- Rust 生成的混排 Word 展示包经过真实 Chromium 渲染：6 个可布局锚点全部绑定、2 处同图引用正确关联、重复姓名只替换指定位置，外部请求为 0。报告和截图保存在忽略提交的 `target/docx-preview-acceptance/`。
- Microsoft Word 通过 COM 只读打开本轮混排源文件、展示副本及已有 Office 验收输出，成功读取段落、表格、图片和页数；这是自动化开档检查，不是人工排版一致性认证。报告位于 `target/docx-preview-acceptance/word-report.json`。
- Windows 独立测试实例通过关闭提示、最小化、托盘菜单、单实例恢复、偏好持久化以及前端不可用时的原生退出回归；未使用正式用户数据。

浏览器回归使用模拟 IPC，文档渲染使用生成的公开测试数据，不替代 macOS 原生验证或真实文件人工验收。本轮未进行 Word/LibreOffice 人工逐页排版检查、未重新运行六份私有简历或测量整机峰值内存。Word 轻量排版的保真程度仍以实际文档和最终输出为准。
